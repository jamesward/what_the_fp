## Type Classes: Inversion of Ad-Hoc Polymorphism

* Typical Overloading
    ```scala
    fun doit(i: Int) = s"number = $i"
    fun doit(s: String) = s"str = $s"
    
    val o1 = doit(1)
    val o1 = doit("asdf")
    ```

* Inverted
    ```scala
    1.doit()
    "asdf".doit()    
    ```
* Nesting
    ```scala
    case class Foo(i: Int, s: String)
    Foo(1, "asdf").doit()
    ```
